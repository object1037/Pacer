# Pacer

![Pacer](./docs/pacer.webp)

Runs an automatic Pomodoro Technique cycle upon powering on.

## How It Works

https://github.com/user-attachments/assets/2add35af-41f7-42f3-8dcc-8eead1801370

Executes a repeating 4-set cycle:

- **Standard Sets (Sets 1–3)**
  - Focus: 25 minutes
  - Break: 5 minutes
- **4th Set**
  - Focus: 25 minutes
  - **Long Break**: 30 minutes

*Note: After the 30-minute long break finishes, the cycle automatically resets to Set 1.*
